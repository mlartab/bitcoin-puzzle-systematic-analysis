# SAFE CLAIMING PROTOCOL

IF YOU ARE READING THIS, YOU FOUND THE KEY. STAY CALM.

1. DISCONNECT FROM THE INTERNET.
2. DO NOT broadcast a transaction using a standard wallet (Electrum, Sparrow) over public Wi-Fi or public nodes.
3. The Bitcoin mempool is monitored by bots. If you broadcast a standard transaction, bots will see the private key (if exposed) or front-run your transaction with a higher fee.
4. You must use a service or a miner that accepts direct, out-of-band transaction submissions (like Flashbots for Ethereum, or direct miner APIs for Bitcoin) or carefully craft a transaction that cannot be front-run.
